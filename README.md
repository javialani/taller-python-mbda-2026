# Taller de Python · MBDA&IA 2026-27

Material de apoyo del taller de Python de la asignatura *Business Analytics I: Fundamentos y herramientas*.

- `index.html`: portada con enlaces a los materiales
- `porque-python/`: presentación interactiva de introducción («¿Por qué Python?»; tecla N para las notas del orador)
- `colab/`: tutorial interactivo de Google Colab
- `sesion1/`: presentación interactiva de la sesión 1 (23 escenas; tecla N para las notas del orador)
- `sesion1/S1_Python_fundamentos_alumno.ipynb`: notebook del alumno de la sesión 1, para abrir en Google Colab
- `sesion2/`: presentación interactiva de la sesión 2 (19 escenas)
- `sesion2/S2_Pandas_Titanic_alumno.ipynb`: notebook del alumno de la sesión 2, para abrir en VS Code con la extensión de Colab (o en Colab)
- `sesion3/`: presentación interactiva de la sesión 3 (20 escenas)
- `sesion3/taller-s3.zip`: kit del alumno (pyproject.toml, uv.lock, datos y notebooks); se prepara con `uv sync`
- `sesion3/S3_combinar_y_auditar_alumno.ipynb` y `sesion3/S3_proyecto_plantilla.ipynb`: notebook de clase y plantilla del proyecto individual
- `sesion3/datos/`: Superstore (datos de ejemplo de Tableau) en tres tablas (`orders`, `returns`, `people`) y un archivo de pedidos por año para `concat`
- `datos/titanic_sucio.csv`: copia «sucia» del registro del Titanic (tipos rotos y 15 fichas duplicadas) para el bloque de limpieza de la sesión 2

Publicado con GitHub Pages (rama `main`, carpeta raíz): https://javialani.github.io/taller-python-mbda-2026/
